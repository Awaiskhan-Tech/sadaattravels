# Sadaat — Travel Agency & Business Management System

Sadaat is a web-based business management system designed for travel agency staff. It brings travel bookings, customer records, accounting, financial reporting, and employee management together in one application.

The system helps organize day-to-day agency operations and maintain business information through a centralized interface.

## Features

### Dashboard
- Access a centralized dashboard for business management.
- Navigate the application's available management features.

### Customer Management
- Create and maintain customer records.
- Search and filter customer information.
- Create, edit, and delete records.

### Travel Booking Management
- Manage travel bookings and reservations.
- Maintain booking-related information within the application.

### Accounting & Financial Management
- Track income and expenses.
- Access accounting and financial reports.
- Organize financial information for business management.

### Employee Management
- Manage employee records.
- Support role-based access through user roles and permissions.

### Authentication & Data Management
- Login and authentication.
- User roles and permissions.
- Store and retrieve application data using the connected backend.
- Search, filter, create, edit, and delete records where supported.

## Technology Stack

- **React** — Building the user interface.
- **TypeScript** — Type-safe application development.
- **Vite** — Development server and build tooling.
- **Supabase** — Backend services and data management.
- **Supabase JavaScript Client** — Connecting the application to Supabase services.

## Application Status

Sadaat is live and being used by a client.

## Intended Users

The application is designed for travel agency staff who need to manage customers, bookings, financial information, and employee records in one system.
